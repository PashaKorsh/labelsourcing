# LabelSourcing Utility

Локальная утилита раздаёт изображения на разметку **без загрузки терабайтов на сервер**.
Картинки лежат на вашей машине; утилита держит исходящее соединение с сервером и отдаёт
файлы по запросу. Работает за NAT без настройки сети.

Принцип: **поставил, привязал, запустил — и забыл**. Все дальнейшие действия (выбор папок,
создание датасетов, пересканирование) выполняются в веб-интерфейсе.

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

## Запуск (3 шага, один раз)

### 1. Привязать утилиту к аккаунту

В вебе: профиль → «Утилиты» → **Получить код**. Скопируйте код и выполните:

```bash
python labelsourcing_utility.py pair --server https://labelsourcing.ru --code ABCD-2345
```

Токен сохранится в `~/.labelsourcing/utility.json`. Повторять не нужно.

### 2. Запустить раздачу, указав корневые папки

```bash
python labelsourcing_utility.py start --root "C:\datasets"
```

`--root` — папка(и), внутри которых лежат ваши наборы картинок. Можно указать несколько:
`--root "C:\datasets" --root "D:\archive"`. Веб сможет заходить **только внутрь этих корней**.

```bash
python labelsourcing_utility.py start --root "C:\datasets" --background   # в фоне
python labelsourcing_utility.py stop                                      # остановить фоновый
```

Корни запоминаются — при следующих запусках можно просто `start`.

### 3. Дальше — всё в вебе

Создайте датасет с типом источника **«Утилита»**, выберите эту утилиту, нажмите
**«Выбрать папку»** — откроется браузер папок вашей машины. Выберите папку → задачи создадутся.
Кнопка **«Пересканировать»** догрузит новые файлы.

## Команды

| Команда | Назначение |
| --- | --- |
| `pair --server URL --code КОД [--name] [--public-url]` | Однократная привязка |
| `start [--root ПУТЬ ...] [--port N] [--background]` | Запустить раздачу |
| `stop` | Остановить фоновый процесс |
| `list` | Показать привязку и корни |

## Прямой режим (без прокси, для белого IP)

По умолчанию картинки идут через наш сервер (прокси) — работает всегда. Если у вас
**белый IP с валидным HTTPS-доменом**, можно отдавать картинки напрямую аннотаторам,
минуя наш сервер (быстрее и конфиденциальнее — данные не проходят через приложение):

```bash
python labelsourcing_utility.py pair --server https://labelsourcing.ru --code ABCD-2345 \
    --public-url https://my-server.example.com
```

`start` поднимет локальный HTTP-сервер (порт `--port`, по умолчанию `8077`) с раздачей и CORS —
проксируйте его наружу своим HTTPS по адресу из `--public-url`. В вебе у датасета снимите
галочку «через прокси», чтобы включить прямой режим.

## Безопасность

- Веб видит и раздаёт файлы **только внутри `--root`** — доступа ко всему диску нет.
- Команды на вашу утилиту может слать только её владелец (проверяется на сервере);
  браузер с утилитой напрямую не общается, токен в браузер не попадает.
- Конфиг и токен: `~/.labelsourcing/utility.json` (переопределяется `LABELSOURCING_UTILITY_CONFIG`).
