# Backend API Routes

Base URL: `/api`

---

## Auth

| Method | Path | Описание |
|--------|------|----------|
| POST | `/api/auth/login` | Авторизация по email/password (OAuth2 form), возвращает JWT токен |

---

## Users

| Method | Path | Доступ | Описание |
|--------|------|--------|----------|
| GET | `/api/users/me` | Любой авторизованный | Профиль текущего пользователя (с ролями и тегами) |
| GET | `/api/users/` | admin | Список всех пользователей |
| PATCH | `/api/users/{user_id}` | admin | Изменить роли и теги пользователя |

---

## Datasets

| Method | Path | Доступ | Описание |
|--------|------|--------|----------|
| POST | `/api/datasets/` | Любой авторизованный | Создать новый датасет |
| GET | `/api/datasets/` | Любой авторизованный | Список всех датасетов со счётчиками задач и разметок |
| GET | `/api/datasets/{dataset_id}` | Любой авторизованный | Детальная информация о датасете со счётчиками |
| PATCH | `/api/datasets/{dataset_id}` | admin | Обновить описание и теги датасета |

---

## Tasks

| Method | Path | Доступ | Описание |
|--------|------|--------|----------|
| POST | `/api/tasks/` | Любой авторизованный | Добавить одну задачу (картинку) в датасет |
| POST | `/api/tasks/batch` | admin | Массовая загрузка задач (список URL) в датасет |
| GET | `/api/tasks/dataset/{dataset_id}` | Любой авторизованный | Все задачи конкретного датасета |
| GET | `/api/tasks/dataset/{dataset_id}/next` | Любой авторизованный | Следующая неразмеченная задача для текущего пользователя |

---

## Labels

| Method | Path | Доступ | Описание |
|--------|------|--------|----------|
| POST | `/api/labels/` | Любой авторизованный | Сохранить результат разметки (полигоны/боксы) |
| PATCH | `/api/labels/{label_id}/status` | admin, moderator | Обновить статус проверки разметки |

---

## Tags

| Method | Path | Доступ | Описание |
|--------|------|--------|----------|
| GET | `/api/tags/` | Любой авторизованный | Список всех тегов |
| POST | `/api/tags/` | admin | Создать новый тег |
| PATCH | `/api/tags/{tag_id}` | admin | Переименовать тег |
| DELETE | `/api/tags/{tag_id}` | admin | Удалить тег |
